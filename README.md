# Unrolled Born/Contrast-Source Inverse Scattering Networks

Code and numerical results for the paper on fixed points, certified boundedness, and noise
sensitivity of deep-unrolled inverse-scattering networks.

## Layout

- `code/` — all experiment drivers and analysis scripts.
- `results/` — JSON logs, reconstruction arrays (`.npz`), and figures.
- `figures/` — PDF figures used in the manuscript.

## Reproducing

The main entry points are:

- `code/run_experiments.py` — train the K=8 network and run the head-to-head baselines.
- `code/run_bjac.py` — Jacobian / noise-accounting measurements.
- `code/run_ablation.py` — projection and budget ablations over 800 layers.
- `code/run_geometry_sweep.py` — cross-geometry generalization.
- `code/run_fresnel_recon_v2.py` — measured-field reconstruction on the Institut Fresnel data.
- `code/gen_numbers.py` — regenerates `numbers.tex` from the JSON logs.

Trained PyTorch checkpoints (`.pt`, ~9 MB each) are excluded from this repository; they are
available from the corresponding author on request.

## Data

Synthetic scattered fields are generated by `code/isp_core.py`. The measured Institut Fresnel
opus-2 data set is not redistributed here; obtain it from the Institut Fresnel website and place
it under `data/fresnel/`.
